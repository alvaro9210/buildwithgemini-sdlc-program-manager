# My agent: SDLC Program Manager Orchestrator
One-liner: A conversational orchestrator agent that helps software organizations lead product initiatives from conception to release with a catalog of specialized SDLC stages and sub-agents.

Tool coverage:
- Memory: Project roadmap, organization tech stack standards, past sprint retrospectives, approved PRDs, and release gate criteria across sessions.
- Tools: Trigger and monitor sub-agents (Requirements/PRD, Coding, Testing, Deployment), query sprint/task progress, update milestone states, and validate release criteria.
- Catalog/UI: Catalog of SDLC pipeline stages, feature backlog items, and sub-agent task cards (with status badges, owners, deliverables, and blockers).
- Image gen: Architecture flow diagrams, milestone badges, or visual UI wireframes synthesized from PRD requirements.
- Sandbox: Sprint velocity analytics, test coverage calculations, and deployment risk score modeling.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for sprint velocity and test metrics, multi-agent orchestration / A2A delegation, Cloud Trace for agent execution monitoring.
